# 4. Extra Features (Backlog)

Not in v1. Add after the core is solid. Top picks marked with ⭐.

## Easy wins

- **Driver check** — find old GPU/chipset drivers. Link to the official page. No auto-install (too risky).
- ⭐ **Disk health** — read SMART data (the disk's own health report). Warn before a drive dies. Saves people's data.
- **Temp monitor** — show CPU/GPU heat. Warn on throttling (the PC slowing itself down from heat). Very real in Egyptian summers.
- **Storage map** — show what eats disk space. Find the forgotten 40 GB of old downloads.
- **Duplicate file finder** — find the same file stored twice.
- **Uninstaller list** — apps sorted by size and last used date. "Not opened in 1 year."

## Gaming

- ⭐ **Per-game boost** — pick a game .exe. When it starts, close chosen background apps. When it closes, restore them. Feels like magic; few tools do it well.
- **FPS overlay** — frames-per-second counter on screen (or a button that turns on the built-in Xbox one).
- **Mouse/keyboard tweaks** — turn off mouse acceleration, sticky keys popups, filter keys.
- **Ping test** — lag test to EU/Middle East game servers. Compare DNS options.

## Work

- **RAM watch** — show top memory-hungry apps live. Offer to close the safe ones.
- **Focus mode** — one click: Do Not Disturb on, chat apps closed.
- **Quick toggles** — one panel for hidden Windows switches: dark mode, night light, clipboard history.

## Security touches (Systevo angle)

- ⭐ **Security score** — Defender on? Firewall on? Updates on? Simple score. Fits the brand.
- **Startup flags** — mark startup items with no signature or odd file paths. Flag only. Never claim malware removal.
- **Hosts file check** — warn if this file changed (malware edits it to redirect websites).

## Power users / business

- **Profile export/import** — save a tweak set as a file. Share it.
- ⭐ **CLI mode** — run silent with a config file. IT teams deploy one profile to 50 PCs. This is the business angle for Systevo.
- **Scheduled maintenance** — weekly clean + re-apply tweaks, silent.
- **Report export** — PDF/HTML report of what was done. Proof for IT work.

## Rule

Ten solid features beat forty weak ones. Add one at a time, test it, then move to the next. An optimizer that slows the PC down is the one trap we never fall into.
