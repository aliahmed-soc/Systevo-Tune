# 8. Branding and Launch

## Identity

- A general PC care tool under the **Systevo** brand. Gaming is a headline feature, not the identity.
- Name: to decide. Must work in English and Arabic. Ideas to explore: Systevo Tune, Systevo Boost, TuneUp by Systevo.
- Tone: honest and technical. No scare screens, no fake health scores.

## Language

- English + Arabic (Egyptian-friendly wording), full RTL layout.
- Arabic UI is a real edge: almost no rival has it.

## Distribution

1. **GitHub** — open source. Trust matters most for a tool that touches the system.
2. **Systevo website** page with screenshots and a short demo video.
3. Portable .exe + installer, both with published hash values (so people can verify the download).

## Known launch problems (plan ahead)

| Problem | Plan |
|---|---|
| Antivirus false positives on unsigned system tools | Sign the .exe if budget allows; publish hashes; open source helps |
| Windows updates reset tweaks | "Re-apply" button now; auto re-apply later |
| "It broke my PC" claims | Undo All + restore point + logs mean every claim can be checked and fixed |

## Free vs paid (later)

- The app itself: **free**. It builds the Systevo name and the portfolio.
- Possible paid tier later: CLI/deploy mode + PDF reports for IT teams.

## Success signals for v1

- 100 downloads with zero damage reports.
- At least one IT admin using it on multiple PCs.
- Every reported issue was fixable with Undo.
