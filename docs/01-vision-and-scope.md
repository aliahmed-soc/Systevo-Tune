# 1. Vision and Scope

## One line

A safe, one-click PC tune-up tool with Gaming and Work modes, in English and Arabic.

## Who it is for

- Gamers who want more FPS and less lag.
- People who work on slow PCs.
- IT admins (later): apply one profile to many PCs from the command line.

## The three modes

| Mode | Goal |
|------|------|
| Gaming | Max speed. High power plan. Fewer background tasks. |
| Work | Balanced. Stable. Battery-friendly on laptops. |
| Custom | User picks each tweak one by one. |

## Positioning (decided)

The app is a **general PC care tool**. Gaming is a headline feature, not the identity.

Why:
- Fits the Systevo brand and looks professional.
- Opens the IT/business use case (CLI deploy mode later).
- A gaming skin gets more downloads, but clashes with the serious image.

## What the app is NOT

- Not an antivirus. It can flag odd things, but never claims to remove malware.
- No "myth" tweaks (RAM cleaners, fake boosters). Only changes we can measure.
- No auto driver installs. Too risky. We check and link, the user installs.
- No cloud, no account, no data sent anywhere. All local.

## Edge over rivals

1. **Full undo.** Most tools cannot undo. This is the core promise.
2. **Arabic + English UI.** Almost no rival has Arabic. Real edge in Egypt and the region.
3. **Honest.** Real numbers, real changes. No fake "PC health 12%!" scare screens.
4. **CLI mode later.** Turns a home app into an IT deployment tool.
