# PC Optimizer — Full Project Plan

A Windows tool that tunes a PC with one click. Two main modes: **Gaming** (max speed) and **Work** (stable and balanced). Built under the Systevo brand.

## Golden rules

1. Every change can be undone. One "Undo All" button.
2. Whitelists only. Never touch unknown files or services.
3. Show before you change. The user always sees the plan first.
4. Quality target: 95% bug-free, 100% recoverable.
